# DECA Roleplay Academy

A single-page DECA training website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — website structure and content
- `style.css` — complete visual design, layout, glassmorphism, gradients, glow effects, responsive design, and animations
- `script.js` — random practice prompts, 5-minute timer, modal resource placeholders, and interactive checklist

## Adding your resource links
In `index.html`, find the resource cards. Replace the placeholder `href="#"` values with your actual document or slideshow URLs.

Example:
```html
<a class="resource-card" href="YOUR_DOCUMENT_LINK" target="_blank" rel="noopener">
```

You can then remove the placeholder modal behavior for that card in `script.js` if you want the card to directly open the resource.

## Free hosting
Upload these files to a GitHub repository and enable GitHub Pages, or upload the folder to a free static host such as Netlify.
