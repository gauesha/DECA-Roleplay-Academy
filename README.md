# DECA Roleplay Academy — Visual Redesign v2

This version contains a stronger visual design: royal blue, periwinkle, lavender and pink gradients; glowing ambient backgrounds; orbit lines; translucent geometric shapes; decorative stars; glass-style panels; editorial typography; distinct resource cards; and responsive layouts.

`index.html` = structure and content
`style.css` = visual design
`script.js` = timer, prompts, modal placeholders, and checklist

The iPad Files app is not a reliable browser preview for a local website with linked CSS and JavaScript. Use a browser preview or upload the files to GitHub Pages to see the actual site.

When your documents are ready, replace the `href="#"` on the resource cards with their URLs.
